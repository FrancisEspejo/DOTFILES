# My Dotfiles

> Personal configuration files for my Linux desktop environment.

![Desktop](assets/desktop.png)

## Overview

This repository contains my personal dotfiles and configurations for a minimal and highly customizable Linux desktop environment.

The setup is built around **bspwm** and **sxhkd**, with a collection of tools and applications that make up my daily workflow.

### Components

* **bspwm** — Tiling window manager
* **sxhkd** — Hotkey daemon
* **Kitty** — Terminal emulator
* **Polybar** — Status bar
* **Rofi** — Application launcher
* **Picom** — Compositor
* **Neovim** — Text editor
* **Zsh** — Shell
* **Powerlevel10k** — Zsh prompt

## Notes

These are my personal configurations, so they may require some adjustments depending on your system, installed packages, hardware, and directory structure.

Feel free to use, modify, or take inspiration from anything in this repository.
